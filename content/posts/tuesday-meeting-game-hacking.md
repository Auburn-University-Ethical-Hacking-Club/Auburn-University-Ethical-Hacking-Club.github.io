#### This Tuesday, we'll be having a high-level overview of game hacking. This presentation aims to provide an overview of the various tools and approaches used in the realm of game hacking.   

### Planned Activities / Covered Topics:

1\. Memory scanning: we explore the method of examining and altering game data in real-time. 

2\. Patching: a technique of directly modifying game files for permanent changes. 

3\. Trainers: specialized programs designed to modify game behaviors without directly altering game files. 

__Attendees will obtain a starting point for further research and experimentation for game hacking and reverse engineering in general_._
